# TimeoffGuru Redesign

A UX/UI redesign concept for **TimeoffGuru**, created to improve usability, functionality, and overall user experience.

## Overview

This project is a redesign of TimeoffGuru, a time-off management platform. The original product felt difficult to use, visually unclear, and not functional enough for the everyday needs of employees and managers.

The purpose of this redesign was to create a cleaner, more intuitive experience that makes requesting time off, reviewing approvals, managing users, and navigating the platform much easier.

## Product Problem

The original TimeoffGuru experience had several usability issues:

- Confusing navigation
- Poor visual hierarchy
- Inefficient task flows
- Difficult approval/request management
- Lack of clarity between employee and manager actions

These problems made the platform feel harder to use than necessary for tasks that should be simple and fast.

## Solution

Redesigned platform with a stronger focus on clarity, structure, and role-based workflows.

The redesign aims to:

- simplify navigation
- improve usability
- make core actions easier to find
- support both employee and manager needs more effectively
- create a cleaner and more modern interface

## Screens Included

The redesign includes:

- **Calendar page**
- **Manager calendar** with **From me / To me** sections for approvals and requests
- **Users page**
- **My Profile**
- **Send a Request**
- **User Profile**
- **Edit User mode** (manager-only)
- **Mobile layouts**


## Goals

- Make the platform easier to understand
- Reduce friction in common tasks
- Improve approval workflows
- Better support different user roles
- Create a more consistent and scalable design system
